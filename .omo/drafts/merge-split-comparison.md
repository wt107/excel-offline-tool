# 表格拆分合并功能调研：方方格子 / Kutools / WPS vs 当前项目

## 一、各平台/插件的实现方式

### 1. 方方格子 (FFCell)

**技术实现**：
- COM Add-in（VSTO技术），C#/VB.NET开发
- 直接调用 Excel Application 对象模型
- 完美兼容32位和64位 Office（2007~365），也支持WPS

**拆分相关功能**：
- **按工作表拆分**：将多工作表工作簿的每个Sheet拆分为独立文件
- **按内容拆分**（按列拆分）：选择某一列作为拆分依据，按列值分组生成多个文件
- **汇总大师**（会员功能）：多薄多表合并、按相同表名合并

**合并相关功能**：
- **合并多表**：一个工作簿中的多个工作表合并到一张表
- **合并多薄**：多个工作簿合并到一个工作簿
- **合并区域**：选定区域合并
- **汇总大师**：按相同表名跨工作簿合并、按行合并

**定价**：基础功能免费，会员8元/月或268元终身

### 2. Kutools for Excel (ExtendOffice)

**技术实现**：
- COM Add-in，支持 Excel 2007~365
- 直接操作 Excel Object Model，格式保留完整

**拆分功能**：
- **Split Data**：按指定列或固定行数拆分数据到多个工作表
- **Split Workbook**：将每个工作表拆分为独立的工作簿/TXT/CSV/PDF文件
- **Split To Columns**：按列拆分打印

**合并功能**（V6.00增强）：
- **A**：将多个工作簿的工作表合并到一个工作表
- **B**：将所有同名工作表合并到一个工作表
- **C**：将多个工作簿合并到一个工作簿
- **D**：跨多个工作簿汇总计算到一个工作表

**定价**：$39 终身

### 3. WPS 表格（智能工具箱）

**技术实现**：
- 内置功能，无需额外安装
- WPS 2026 v12.6 已支持一键拆分

**拆分功能**：
- **按内容拆分**：选择拆分区域→选择拆分依据列→选保存路径，一键按列值生成多个文件
- **按工作表拆分**：工作簿按工作表拆分为多个独立文件
- 支持自定义命名规则（前缀、日期、序号）

**合并功能**：
- **按行合并**：多个工作表内容按行追加到一张表
- **按相同表名合并**：跨工作簿合并同名Sheet的内容
- **整合成一个工作簿**：多个工作簿的所有Sheet合并到一个工作簿
- **按相同表名整合工作簿**：多个工作簿中同名Sheet合并

**定价**：合并拆分功能需要WPS会员

## 三、实现原理对比

### 插件方案（方方格子 / Kutools）

```
Excel/WPS 进程 → COM Add-in (VSTO/C#)
       ↓
   Excel Object Model
       ↓
  直接操作: Workbook.Worksheets.Cells
       ↓
  操作结果即时反映在 Excel 界面
       ↓
  用户点击保存 或 另存为
```

**优点**：
- 格式保留最完整（Excel内部格式）
- 公式引用自动更新（对象模型处理）
- 样式索引在工作簿内部一致
- 大文件性能优（由Excel进程管理内存）
- 支持撤销操作

**缺点**：
- 需安装，需Office/WPS
- 仅Windows
- 方方格子部分功能收费
- 对Excel版本有要求

### 内置方案（WPS智能工具箱）

```
WPS 进程 → 智能工具箱插件（内置C++）
       ↓
   WPS 表格对象模型（兼容Excel OM）
       ↓
  拆分/合并操作 → 新文件生成
       ↓
  WPS会员校验（部分功能）
```

**优点**：
- 无需额外安装
- 2026版已做到一键拆分
- 与WPS生态深度整合

**缺点**：
- 合并拆分功能需会员付费
- 仅WPS环境
- 仅Windows/Mac

### 纯前端方案（当前项目 excel-offline-tool）

```
浏览器 → 用户打开 excel.html
       ↓
   FileReader API 读取文件 (ArrayBuffer)
       ↓
   SheetJS (xlsx.full.min.js) 解析
       ↓
   JS 操作 JSON 格式数据
       ↓
   SheetJS 写入 → Blob → URL.createObjectURL
       ↓
   用户点击下载
```

**优点**：
- **零安装**：双击HTML即用（或任何静态服务器）
- **跨平台**：任何有浏览器的设备（Win/Mac/Linux）
- **完全离线**：不依赖网络，不上传数据→**隐私安全**
- **便携**：单个HTML文件+2个lib库，U盘即走
- **独特功能**：竖向列拆分（目前已知竞品均无此功能）

**缺点**：
- **浏览器内存限制**：大文件（>50MB）可能卡顿
- **公式引用偏移手动处理**：不完整，复杂公式可能失败
- **跨工作簿样式索引问题**：需stripStyle处理
- **无撤销**：每次操作是独立的生成-下载流程
- **不支持WPS特有格式**（.et等）

## 四、差异化分析：当前项目的定位

### 核心差异点

| 维度 | 方方格子/Kutools/WPS | 当前项目 |
|------|-------------------|---------|
| **目标用户** | Excel深度用户、需频繁处理数据者 | **偶尔处理Excel的用户**、隐私敏感者、跨平台工作者 |
| **使用场景** | 日常办公，高频处理 | **临时应急**、文件交接、隐私场景（不上传服务器） |
| **依赖** | Office/WPS + Windows | 任何浏览器 |
| **学习成本** | 需了解Excel操作 | **零门槛**，向导式步骤 |
| **功能范围** | 几百个功能（含拆分合并） | **专精**5种拆分合并场景 |

### 当前项目的独特价值

1. **"临时救急"场景**（竞品无法替代）：
   - U盘里只有这个HTML → 任何电脑打开即用
   - 同事发来Excel需要快速拆分 → 无需安装任何软件
   - 敏感数据文件 → 不上传任何服务器

2. **竖向列拆分**（竞品缺失）：
   - 将多列表格按列拆分为多个单列文件
   - 方方格子、Kutools、WPS均无此功能

3. **安全审计级输入验证**（竞品忽略）：
   - 魔术字节校验（防伪冒文件）
   - XSS防护（textContent代替innerHTML）
   - CSP策略保护

4. **测试覆盖率**（同类项目少见）：
   - 122项内嵌自测 + 8个Playwright E2E
   - 测试即文档，可离线运行

### 当前项目的短板（对比竞品）

1. **大文件处理能力不足**：浏览器内存限制，Excel进程可处理GB级
2. **公式保留不完整**：手动shiftFormulaRefs覆盖不够全面
3. **无实时预览**：插件方案可在Excel中直接操作、预览结果
4. **无撤销/回退**：生成文件即最终结果，不支持逐步编辑

## 五、结论

**当前项目的定位应该坚持"轻量级离线工具"，而非与方方格子等插件正面竞争。**

- 方方格子/Kutools 是 "瑞士军刀"（功能多但繁重）
- WPS内置是 "制服工具"（平台绑定+付费）
- 当前项目是 "一次性手术刀"（专精、轻量、隐私）

**如果未来要扩展功能，建议优先考虑**：
1. **按相同表名合并**（WPS有、方方格子有、本项目无）——用户需求高
2. **按固定行数拆分**（Kutools有、本项目无）——常见场景
3. **批量命名规则**（WPS有、本项目无）——用户体验提升
4. **文件拖拽到浏览器直接打开**（减少双击HTML的步骤）

**不建议进入的领域**：
- 与方方格子比拼功能数量（几百个功能 vs 5个）
- 处理100MB+大文件（浏览器天生受限）
- 实时公式计算（SheetJS不做公式引擎）
