# 功能对比报告：本工具 vs Excel / WPS / Python pandas

## 一、核心功能对比表

| 功能 | 本工具 | Excel 自带 | WPS 高级功能 | Python pandas |
|------|--------|-----------|-------------|---------------|
| **按工作表拆分** | ✅ 支持（ZIP/单文件） | ⚠️ 需VBA宏 | ✅ 支持 | ✅ `df.to_excel(sheet_name)` |
| **按列拆分（横向）** | ✅ 单列分组 | ❌ 不支持 | ⚠️ 部分支持 | ✅ `df.groupby(col)` |
| **按列拆分（竖向）** | ✅ 支持 | ❌ 不支持 | ⚠️ 部分支持 | ✅ 需手动实现 |
| **按行数拆分** | ✅ 支持 | ❌ 不支持 | ❌ 不支持 | ✅ 需手动实现 |
| **文件合并** | ✅ 多文件→多Sheet | ⚠️ Power Query | ✅ 支持 | ✅ `pd.concat` |
| **工作表数据合并** | ✅ 多Sheet→单Sheet | ⚠️ 需复制粘贴 | ✅ 支持 | ✅ `pd.concat` |
| **智能合并（模式A/B）** | ✅ 模式A全量追加/模式B归类 | ❌ 不支持 | ❌ 不支持 | ⚠️ 需脚本实现 |
| **合并计算（求和/计数等）** | ✅ 支持 | ✅ 数据透视表 | ✅ 数据透视表 | ✅ `groupby().agg()` |
| **数据匹配（JOIN）** | ✅ 内/左/右连接 | ⚠️ Power Query | ⚠️ 部分支持 | ✅ `pd.merge` |
| **去重（整行）** | ✅ 支持 | ✅ "删除重复项" | ✅ "删除重复项" | ✅ `drop_duplicates()` |
| **去重（按指定列）** | ✅ **本次新增** | ✅ "删除重复项"可选列 | ✅ "删除重复项"可选列 | ✅ `drop_duplicates(subset=[])` |
| **数据预览** | ✅ **本次新增**（前50行） | ✅ 直接打开文件 | ✅ 直接打开文件 | ✅ `df.head()` |
| **离线运行** | ✅ 纯前端，无服务器 | ✅ 本地软件 | ✅ 本地软件 | ⚠️ 需Python环境 |
| **批量处理** | ✅ 支持 | ⚠️ 需VBA/PQ | ⚠️ 需插件 | ✅ 支持 |
| **大文件处理** | ✅ Time-Slicing防卡死 | ⚠️ 可能卡顿 | ⚠️ 可能卡顿 | ✅ 内存充足即可 |
| **格式保留** | ✅ 保留样式/公式 | ✅ 完整保留 | ✅ 完整保留 | ⚠️ 仅数据 |

## 二、差距分析

### 本工具优势
1. **零安装**：浏览器打开即用，无需安装 Excel/WPS/Python
2. **隐私安全**：文件不上传服务器，纯本地处理
3. **批量自动化**：一键处理多个文件，无需手动复制粘贴
4. **智能合并模式A/B**：Excel/WPS 无内置等价功能
5. **按行数拆分**：Excel/WPS 无内置功能
6. **JOIN 数据匹配**：比 Excel VLOOKUP 更灵活

### 本工具劣势
1. **公式保留有限**：merge-sheet 模式会丢失公式（转为静态值）— SheetJS 库限制
2. **无图表保留**：仅处理数据，不保留图表对象
3. **预览行数限制**：仅前50行，Excel/WPS 可完整浏览
4. **无筛选/排序交互**：处理前无法交互式筛选数据
5. **多列组合拆分**：不支持（pandas `groupby([col1, col2])` 支持）

## 三、对标结论

| 场景 | 推荐工具 |
|------|---------|
| 简单去重、透视表 | Excel / WPS 自带 |
| 复杂数据清洗、分析 | Python pandas |
| 批量拆分/合并、无安装环境 | **本工具** |
| 隐私敏感数据（不能上传） | **本工具** |
| 保留完整格式+公式 | Excel / WPS |
| 自动化流水线 | Python pandas |
