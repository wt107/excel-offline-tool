| 维度 | 描述 |

| **项目名称** | Excel 离线浏览器工具 v1.5.3 |

- ✅ **功能全面**：9种处理模式，覆盖主流拆分合并需求
- ✅ **离线可用**：内网环境完全可用，不依赖外网

## 三、业务功能分析

### 3.1 功能模块详细分析

#### 3.1.1 按工作表拆分（split-sheet）

| 维度 | 说明 |
|------|------|
| **输入** | 单个Excel文件（.xlsx/.xls/.xlsm） |
| **输出** | ZIP包（多个xlsx文件）或单文件多Sheet |
| **配置项** | 命名模板、保留底部行数、处理模式、输出格式 |
| **核心逻辑** | 遍历选中的工作表，使用cloneWorksheet深拷贝，保留所有格式 |
| **特色功能** | 空表自动跳过、31字符Sheet名限制处理 |

**处理流程**：
```
上传文件 → 解析Excel → 显示工作表列表 → 用户选择 → 配置选项 → 逐Sheet处理 → 生成ZIP/单文件 → 下载
```

#### 3.1.2 按列拆分-横向（split-column）

| 维度 | 说明 |
|------|------|
| **输入** | 单个Excel文件 |
| **输出** | 按列值分组的多个文件 |
| **配置项** | 表头行数、拆分列、命名模板、保留底部行数 |
| **核心逻辑** | 按指定列的唯一值分组，每组生成一个文件 |
| **特色功能** | 支持多列组合分组、空值归类为"[空值]" |

**处理流程**：
```
上传文件 → 选择工作表 → 预处理分析 → 数据提取与分类 → 工作簿生成 → 输出管理
```

#### 3.1.3 按列拆分-竖向（split-column-vertical）

| 维度 | 说明 |
|------|------|
| **输入** | 单个Excel文件 |
| **输出** | 每个数据列一个文件（固定表头列+数据列） |
| **配置项** | 表头行数、固定表头列、数据列选择 |
| **核心逻辑** | 使用copyWorksheetByColumnDeletion保留格式 |
| **特色功能** | 强制ZIP输出、列删除时安全处理合并单元格 |

#### 3.1.4 按行数拆分（split-rows）

| 维度 | 说明 |
|------|------|
| **输入** | 单个Excel文件 |
| **输出** | 按固定行数分块的多个文件 |
| **配置项** | 每份行数、表头行数、命名模板 |
| **核心逻辑** | 按行数切分数据，每份都复制表头 |
| **特色功能** | 保留格式模式下使用copyWorksheetByDeletion |

#### 3.1.5 文件合并（merge-file）

| 维度 | 说明 |
|------|------|
| **输入** | 多个Excel文件 |
| **输出** | 合并后的单个文件（每个文件的工作表作为独立Sheet） |
| **配置项** | 搜索过滤、视图切换（按文件/按名称） |
| **核心逻辑** | 遍历文件，使用getUniqueSheetName处理Sheet名冲突 |
| **特色功能** | 重复文件检测、魔术字节验证 |

#### 3.1.6 工作表数据合并（merge-sheet）

| 维度 | 说明 |
|------|------|
| **输入** | 多个工作表（可跨文件） |
| **输出** | 合并后的单张总表 |
| **配置项** | 表头行数、合并策略（全量追加/按名称归类） |
| **核心逻辑** | 表头一致性验证 + 数据纵向堆叠 |
| **特色功能** | 表头不一致自动跳过、列数不足检测 |

#### 3.1.7 智能合并大师（smart-merge）

| 维度 | 说明 |
|------|------|
| **输入** | 多个Excel文件 |
| **输出** | 智能合并后的文件 |
| **模式A** | 全量纵向追加（单Sheet输出） |
| **模式B** | 按工作表名称归类（多Sheet输出） |
| **特色功能** | 来源列固定位置、Sheet名归一化、去重算法 |

#### 3.1.8 合并计算（summary-merge）

| 维度 | 说明 |
|------|------|
| **输入** | 多个工作表 |
| **输出** | 按关键列分组汇总的计算结果 |
| **计算方式** | 求和、计数、平均值 |
| **核心逻辑** | 按关键列分组 + 聚合计算 |

#### 3.1.9 数据匹配（data-join）

| 维度 | 说明 |
|------|------|
| **输入** | 两个工作表 |
| **输出** | 匹配后的结果 |
| **匹配方式** | 内连接、左连接、右连接 |
| **核心逻辑** | 类似SQL JOIN操作 |

       const CHUNK_SIZE = options.chunkSize || 500;

           const chunk = items.slice(i, Math.min(i + CHUNK_SIZE, total));
           for (const item of chunk) { processFn(item); }
           if (i + CHUNK_SIZE < total) {
