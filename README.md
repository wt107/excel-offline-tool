# Excel 离线浏览器工具 v1.5.5

纯前端 Excel 拆分与合并工具，无需安装、无需上传服务器，浏览器直接打开即用。

## 功能

| 功能 | 说明 |
|-----|------|
| 按工作表拆分 | 多工作表 Excel → 多个独立文件 |
| 按列拆分（横向） | 按指定列值分组拆分 |
| 按列拆分（竖向） | 多列拆为多个文件 |
| 按行数拆分 | 每 N 行拆分为一个文件 |
| 工作表管理 | 对多工作表文件勾选删除 / 重命名 / 调整顺序，导出为单个文件 |
| 文件合并 | 多个 Excel → 一个工作簿（可逐页勾选、预览每页内容） |
| 工作表数据合并 | 多工作表数据 → 一张总表（默认按列名智能对齐表头） |
| 智能合并 | 模式A 全量追加（支持按列去重）/ 模式B 按名称归类 |
| 数据预览 | 上传文件后预览前50行数据；合并前可预览每个工作表表头与前几行 |
| 合并计算 | 按关键列分组汇总（求和/计数/平均值） |
| 数据匹配 | 类似 SQL JOIN（内连接 / 左连接 / 右连接） |

## 快速开始

## 多工作表与表头对齐

- **多页文件**：文件合并 / 工作表数据合并 / 智能合并在选择页时，多页文件会以"N 页"徽标高亮显示，并可用"预览"按钮查看每个工作表的表头与前几行，方便在合并前确认各页内容。
- **工作表数据合并的表头对齐**：默认使用「标题匹配」——按列名自动对齐，允许各文件列顺序不同、列数不同，缺失列留空、新增列自动追加，避免表头不一致时数据被静默跳过。若需要精确控制，也可手动切换为「智能追加」（按位置）或「严格追加」（要求完全一致，不一致的表会被跳过并提示）。
- **表头结构差异的自动处理**：真实文件中常出现「一个文件第一行是大标题、第二行才是列名」，而另一个文件第一行就是列名。标题匹配模式会自动识别这类**标题行**（首行内容稀疏、第二行才是完整列名），仅对该文件跳过标题行并按第二行列名对齐，避免整表数据错位。合并前的预览会提示"已识别含标题行"的文件名，方便核对。若各文件存在多行表头，可手动调整「表头行数」。
- **工作表管理**：对单个多工作表文件勾选要保留的页、重命名、调整顺序，再导出为单个文件；可选择「保留格式」或「仅数据」。

## 数据匹配与合并计算的健壮性

- **数据匹配（JOIN）关键列归一化**：匹配前自动忽略关键值两端的空格、将全角字符转半角、忽略大小写，并对"纯数字"去除千分位/货币符号后按数值归一——避免"看起来一样却匹配不上"的静默丢数据（如 `'张三 '` 与 `'张三'`、`123` 数字与 `'123'` 文本、`'1,234'` 与 `1234`）。工号/编码类前导零（`'00123'` vs `'123'`）仍按字符串区分，不强行相等。
- **数据匹配内连接语义**：内连接只保留左右两表都匹配到的行；右连接才追加右表独有的行。匹配结果会显示"左表 N 行未匹配"，未匹配时给出提示。
- **数据匹配工作表选择**：若用户在某文件中只勾选了一个工作表，匹配使用该工作表；默认全选时回退到该文件第一个工作表。
- **合并计算数值解析**：求和/平均/最大/最小会自动解析千分位（`1,234`）、货币符号（`￥500`）、全角数字（`２５０`）等"看似数字的文本"；无法解析的单元格会作为非数值忽略，并在结果中提示"忽略 N 个非数值单元格"，避免金额被静默丢成 0。
- **合并计算计数**：计数针对"非空单元格"统计（文本列也可计数），而非只统计数值单元格。
- **文件大小限制**：数据合并/合并计算/数据匹配等所有合并类模式均与拆分模式一致，超过 50MB 的单文件会被拒绝并提示，避免浏览器崩溃。
- **格式说明**：数据合并/智能合并/合并计算/数据匹配输出的都是"纯数据表"（含来源列/统计列），不保留原表的字体、边框、合并单元格、列宽与数字格式，相关选项面板均有提示；如需保留原始格式请用「工作表管理」。

## 已知限制

| 限制 | 说明 |
|------|------|
| 合并后公式不保留 | 合并操作（merge-sheet / smart-merge 模式A）使用 `sheet_to_json` 重建数据，公式 `f` 属性丢失，仅保留计算值。这是 SheetJS 库的设计限制 |
| 无撤销/历史记录 | 本工具定位为一次性离线处理工具，不保留操作历史。误操作请重新上传文件处理 |
| 单文件架构 | 故意保持为单 HTML 文件（零构建依赖、双击即用），不拆分为模块化项目 |

## 隐私

所有数据仅在本地浏览器处理，不上传任何服务器。

## 技术栈

- HTML5 + CSS3 + JavaScript（纯原生，无框架）

- [JSZip](https://github.com/Stuk/jszip) v3.10.1 — ZIP 生成
